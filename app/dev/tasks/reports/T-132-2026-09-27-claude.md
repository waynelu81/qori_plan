# T-132 — report

## Outcome

A Series has a class chat. On the Series page the creator adds the way into
the group their class talks in: a WhatsApp, WeChat, WeCom or other group's
invite link, or its QR code image uploaded to Qori with the date printed under
it, which choosing WeChat fills in a week ahead. They can edit it and remove
it, one per Series for now. A Peer with access finds a "Join the class chat"
card above the Episodes. "Join the chat" or "Show the code" goes through a
route that checks the Access and logs one `access_opens` row, target `chat`,
then sends them to the invite or to a signed link to the image in a new tab.
"I've joined" folds the card away on that browser. After the printed date the
Peer's card says the code has expired and offers nothing to follow, the
creator's page warns them to replace it, and a stale "Show the code" lands back
on the card with one sentence. Removing a chat, replacing its code and purging
the Series each delete the image and its upload row, the chat row first. The
invite never reaches the Peer's page props or the public page, and Qori calls
no chat vendor.

## Departures

- **`errors.chats.url_invalid`**, one line for a link that is not https or
  is too long, so the field does not show Laravel's default English.
- **Cases 3 and 5 also call the service**, so its own copy of the request's
  way-in and code checks is tested; the counts stay 14 and 12.
- **WeChat's help line shows only when WeChat is chosen**, since it states
  WeChat's rule; a code of another app has the date field without it.
- **The creator's panel is hidden on an archived Series**, as Details is, and
  **the Peer's card on a purged one**, whose chats the purge has deleted.
- **The factory's default builds a Group and a Series of its own**, as
  `MaterialFactory` does, rather than refusing without `forSeries()`.
- **The kind radios are named per form** (`chat-{id}-kind`), so the add form
  and an edit form never share one radio group once the cap allows both.
- **The components use the Wayfinder route helpers**, as `LiveSessionPanel`
  does, not string URLs.
