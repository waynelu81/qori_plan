# T-033 — report

## Outcome

The creator's dashboard no longer offers work on a Series that has been taken
out of circulation, and the read-only banner counts the way the rule that
produced it counts. One filter on one query, `->unarchived()`, plus the four
tests that should have existed since `T-009` added archiving.

The fix is one line. The finding underneath it is the point: `$series->count()`
in the digest and `Group::seriesUsed()` were two computations of one number,
a few lines apart, disagreeing. Filtering in the query makes them agree by
construction rather than by two people remembering the same rule.

## Found, not fixed

- **`R-002` F-1 understated the severity.** The pass photographed "Add the first
  Episode" on an archived Series and called it misleading. The same code path
  also produced "Make ready to share" on an archived Series, which `publish()`
  refuses outright — a primary call to action leading to a guaranteed refusal,
  which `PLAN.md`'s beta gate forbids by name. Reproduced in a test rather than
  argued: the failure message read _"Retired Course is ready to share"_.
- **The fifth duplicate count.** `T-009` found four places the Series cap was
  computed and fixed them. This was the fifth, and it survived because the count
  and the cap were reached by different code paths. There is no test anywhere
  asserting that every count of this number agrees; a property test that walked
  them would be worth more than a sixth fix.
- **Seven `R-002` findings remain unrouted.** F-2 is the next one worth doing:
  `Payouts.vue` links every viewer to billing, `BillingController` throws for
  non-owners, and the sidebar already gates it. It needs no controller change,
  because `auth.currentGroup.isOwner` is already a shared prop.
- **Positive `tabindex` on sign-in and register.** Named in
  `ui-components-and-sign-in.md` inside a validation checklist rather than as a
  finding. `Login.vue` carries 1 through 5 with 5 used twice; `Register.vue`
  carries 1 through 4. Those controls are pulled into a tab sequence ahead of
  everything else on the page, including skip links. It is fixable independently
  of any sign-in redesign.
