# T-051 — report

## Outcome

The route half of `qori:reachability` no longer counts a route's own
registration, or a test that visits it, as a way in: it reads `.vue` and
`.ts` files and PHP under `app/` only. Before, every named route matched its
own `->name()` in `routes/`, so the half could not report a named route at
all. Three cases pin it, one per door: a route named only in `routes/` is
reported, one visited only from a test is reported, and one a controller
redirects to still counts.

The first honest run still reports no route, and that is not the clean bill
it looks like. Three routes pass only because a developer command names them;
each is reachable in the product through a shape the scan cannot read. They
are written up in `app/dev/reachability.md` and drafted as `T-208`.
