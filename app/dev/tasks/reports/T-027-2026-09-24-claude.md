# T-027 — report

## Outcome

The Series page now confirms who is getting the Series. Signed in, it says
"You're getting this as :name (:email)." above the button, with "Not you?
Sign out", the ordinary sign-out that lands on sign-in. The timezone is asked
once, where the person already is: a guest on the name-and-email form, carried
through the code and saved only when the code proves an account with none;
somebody signed in with none above the button; somebody with one is told it
and not asked. A priced Series, or an invitation at a price, says the code
confirms the address and payment on Stripe follows. While a payment this
browser started is being confirmed, the page offers Check now (the Confirming
page) and "Didn't pay? Start again" instead of selling it again, and a second
checkout or a second priced Accept goes to Confirming rather than opening a
second Stripe session. An invitation's full address is in the page data only
while it is waiting for the person viewing it.
