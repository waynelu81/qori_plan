# T-156 — report

## Outcome

Removing an Episode now deletes its file and its upload record with it;
purging a Series deletes the upload records it used to strand; and deleting an
account deletes every file of the Group that person owns before the cascade
takes the rows. None of the three deletes a file its Group's own register does
not hold, or one another of the Group's Episodes still names. That closes a
hole that was already open: `purge()` deleted whatever path an Episode named,
so a creator could have another Group's file deleted by pointing an Episode of
their own at it and deleting the Series.
