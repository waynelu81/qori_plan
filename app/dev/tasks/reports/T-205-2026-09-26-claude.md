# T-205 — report

## Outcome

Deploys run their migrations again, and the pending ones applied: the release
with `T-125` to `T-131`, `T-128` and `T-204` went live on 26 September 2026 at
09:39 UTC, after two deploys had failed in `php artisan migrate --force` with
`SQLSTATE[25P02]: current transaction is aborted`. Production reaches Neon
through its pooler, PgBouncer in transaction mode, which neither a migration's
transaction nor PDO's server-side prepared statements survive. The `pgsql`
connection now names Neon's direct endpoint, which turns on Laravel 13's
pooled/direct support: migrations and schema changes run on the direct
endpoint, and every query through the pooler emulates its prepares — which
also covers the multi-statement transactions a request makes. `laravel/framework`
is `v13.33.0`.
