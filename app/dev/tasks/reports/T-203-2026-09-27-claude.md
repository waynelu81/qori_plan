with no current Group and no remembered vocabulary. `Tests\TestCase` forgets
the container's scoped instances at the start of `call()` and `artisan()`, and
leaves what a request set in place afterwards, so a test's assertions still
read the rows its requests wrote. Ten hand-written workarounds in eight test
files are gone; four new cases prove the reset, and each fails without it.
