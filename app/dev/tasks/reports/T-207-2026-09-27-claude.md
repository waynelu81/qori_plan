# T-207 — report

## Outcome

Each row of the creator's Peer list now says, under the address, whether that
Peer has opened the class chat: "Opened the class chat on 27 Sep 2026." with
the day of their latest open in the Group's zone, or "Hasn't opened the class
chat yet." It counts only the chat the Series has now — a chat removed and
added again starts afresh, an edited one keeps its opens — and says nothing
while the Series has no chat. It says "opened", never "joined", because Qori
cannot see the chat. The whole list is read in one query.
