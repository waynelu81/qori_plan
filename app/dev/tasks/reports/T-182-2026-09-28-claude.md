# T-182 — report

## Outcome

The pages the task named no longer log a hydration mismatch, at 375 or
1280px. Two causes. Money and dates were formatted in the runtime's own locale,
so Node's (the machine's, `en-AU` here) and the browser's disagreed: the
server wrote "$89.00" and "GBP 30", the browser "A$89.00" and "£30". A shared
`locale` prop, the first language of the request's `Accept-Language`, now goes
to `formatMoney()`, `Pricing.vue`, every date call and `SessionTime`, so both
renders use the reader's locale — `T-058`'s rule, kept. And at a phone's width
the sidebar decided "mobile" in the browser's first render, where the server,
with no window, had rendered the desktop one; `SidebarProvider` now gives
`useMediaQuery()` an `ssrWidth`, so the first render assumes a desktop on both
sides and the real width follows as an update.
