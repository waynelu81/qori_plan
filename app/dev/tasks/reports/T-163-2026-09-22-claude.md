# T-163 — report

## Outcome

Disconnect lets go of every account Stripe answers for. When Stripe refuses to
deauthorize — as it does for any account Qori made on Accounts v2, the kind the
owner could not disconnect on 21 September — Qori logs Stripe's code and clears
the account anyway, and the owner reads "Stripe is disconnected". Only Stripe
not hearing the request (no answer, or a server error) stops the disconnect,
with the account kept and the error shown.
