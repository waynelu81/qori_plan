# T-057 — report

## Outcome

Every share action under `/g/{group}` that declares `string $group` now
receives the Group's slug, as its signature says, instead of the whole Group
turned into JSON. `SetCurrentGroup` still finds the Group from the slug and
puts it in `CurrentGroup`, but no longer writes the model back onto the route.
An action that type-hints `Group` still gets the model from Laravel's binding,
and a slug that names no Group still gets Qori's deliberately vague not-found
page. Nobody sees a difference today, because every action takes its Group from
`CurrentGroup`. The next one to build a link from `$group` will work, where
`T-054`'s threw an error carrying the Group's JSON.
