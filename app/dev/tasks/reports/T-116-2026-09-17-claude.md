# T-116 — report

## Outcome

Qori's `/.well-known/passkey-endpoints` document names `enroll` and `manage`
again, both pointing at the security page, so a password manager that reads it
can send a person straight to where they create a passkey. The 9 September
rename had turned `enroll` into `grantl`, which no password manager reads. A
test now holds the document's exact keys and values, and `docs/flows/auth.md`
describes the document and names the sharing prefix `/g/{group}/*`, not `/w/`.
