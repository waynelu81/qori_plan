# T-126 — report

## Outcome

A live Episode keeps its recording now. On the creator's Series page each
live row with no recording offers **Add the recording link**; the link and
its passcode are published the moment they are saved, and the row lists them
as "Part 1 · Added by you on 26 Sep 2026 · the link · the passcode". On the
Peer's card, once Join's window has closed, a visible recording makes the
state `ready`: "The recording is here. It's a link the Creator manages, so if
it stops working, let them know.", then **Watch recording** — or Watch part 1,
Watch part 2 — with the passcode beside it. Watch is the Open route with
`?recording=`: it passes the same gate as Join, marks the Episode opened,
writes one `access_opens` row with `target = recording`, and redirects to the
pasted link, which never reaches a page a Peer can read. A hidden, held or
foreign recording is Qori's 404, "That recording isn't available." Nothing is
emailed yet; that is `T-128`.

## Departures

- **The panel's form is a toggle**, for the reason in the table above, with
  a Close button reusing `series.live.edit.close`; `live.copy.recording`
  carries it as `close`.
- **A live row with no start** — which `T-125` found can exist — takes the
  paste time as `started_at` and the default length as `duration_minutes`,
  rather than failing `D-027`'s not-null. Its card stays hidden until it has a
  start (`T-125`'s `isScheduled()`).
- **The card re-derives `ready` on its own tick**: when the server said
  `open` and the window closes while the page is open, a card with
  recordings moves to `ready`, not `waiting`, matching the server's order.
- **`RecordingController::store()` takes `LiveSessionService`** to choose
  between the two toasts, and `lang/en/series.php` gains
  `recording_added_after_session`. One case beyond the 22,
  `test_a_paste_before_join_closes_says_after_the_session`.
- **`Episode` gains `@property string $series_id`** in its docblock, beside
  the three members the spec lists.
- **Four docs beyond the Files table**, under Added during execution:
  `docs/flows/storage.md`'s Open chain gains `?recording=`;
  `docs/flows/series.md`'s "Not built yet" says the creator pastes the link
  and nothing finds one; and the two README rows name recordings. The tinker
  recipe's `T-125` section now reads `stateFor()` inside `runFor()`, because
  past `open` it reads group-scoped rows and threw with no Group.

## Found, not fixed

- In `ready` the card offers Watch and no "Join again", though the route
  admits Join until the grace ends: a recording pasted mid-session takes the
  way back into an overrunning class away 15 minutes after the scheduled end
  instead of 120. `T-127` edits the card's grace secondary for
  `not_recorded` and takes this with it → T-127
- Past `open`, `stateFor()` reads the Episode's recordings, which are
  group-scoped, so a caller with no current Group throws; and
  `visibleRecordings()` reads the loaded relation, so an Episode instance
  loaded before a paste answers from before it. `T-128` and `T-129` already
  run inside `runFor()` and eager-load; `T-131`'s `isReleased()` calls it from
  the Peer surface, which has no Group → T-131
