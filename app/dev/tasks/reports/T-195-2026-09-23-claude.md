## Departures

- **A rename moves the URL only when the name changed.** The first suite run
  caught it: the card saves the name beside the timezone, so a timezone-only
  save re-slugged any Group whose slug never matched its name, and the page
  the test then loaded answered 404. `rename()` compares before it moves
  anything; `test_saving_the_same_name_keeps_the_url` holds it.
- **`GroupRenameTest::test_renaming_does_not_move_the_group` became
  `test_renaming_after_a_publish_does_not_move_the_group`.** Its reason — links
  already sent — holds from the first publish, which the case now arranges.
  Added during execution.

- Integrations clears both forwarding addresses on a visit that names no
  Series, and a test says so.
- The e2e helpers and `EndToEndCommand`'s description, rewritten to the new
  first ten minutes.
- `GroupNameForm.vue`'s `submitLabel` comment no longer mentions setup.

## Found, not fixed

- `composer ci:check` does not run the browser journeys, so a change to the
  first screens can pass the gate while every journey fails, as `T-026` did.
  → decided: not a task — the journeys need Mailpit and a browser, and
  `PROCESS.md` already asks for a state-specific browser walk; the `T-026`
