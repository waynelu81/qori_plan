# T-123 — report

## Outcome

A live Episode now has an end, and its start lives in one place. A creator
adding one gives it a join link from Zoom, Teams or any other host
("Another meeting link — Meet or anything else", `EpisodeProvider::Link`), a
start typed in the Group's zone, a length in minutes (60 unless changed,
twelve hours at most) and a Recorded / Live only switch. Their Series page
row reads the start and the end as one range in the Group's zone with the
zone named, then Recorded or Live only, then "No join link yet" when there
is none. `episodes.ends_at` is new; the start is no longer copied into
`content`, and every live row that already existed has an end an hour after
its start, `records` true and no start in its payload. Every number the
classroom stream will read is declared once in `config/qori.php`, and
`LiveSessionPanel.vue` exists for `T-124` onwards to edit rather than the page.
