# T-082 — report

## Outcome

Cursor and Claude Code now start from the same rules. `CLAUDE.md` is the one
source of conventions; the four `.cursor/rules/*.mdc` files are front matter
and a pointer at it, and `DocumentationTest` fails the moment one of them grows
a rule of its own. The conventions that were prose are now checked:
`ArchitectureTest` walks `app/` for vendor HTTP in a Service, `env()` outside
config, inline `validate()`, a sentence passed to `__()`, a raw
`$request->user()`, anything `ShouldQueue`, and an Integration importing a
layer above it — each with an allow-list carrying a reason per entry and a
companion check that every allowed path still exists. The four inline
validations this task owned are Form Requests, the one inline toast is a lang
key, and the two comments claiming a flashed toast never shows after a full
page load say why the inline notice is used instead (Inertia does fire the
flash event on the initial page).

The documents a developer is sent to now describe the code as it is.
`docs/architecture/` holds the stack, tenancy, sessions, errors and the admin
console in the current nouns, with `project-plan.md` §20–24 stubbed to point
there and dated; `CLAUDE.md` rule 1 sends people to the new files. No live
document says episodes are embedded, that Postmark is unwired, or that a
model is called Course, and a second `DocumentationTest` case keeps it that
way over `CLAUDE.md`, `docs/flows`, `docs/tinker`, `docs/architecture` and
`.cursor` — never over the planning history. `docs/flows/billing.md` and
`docs/flows/onboarding.md` are new; payouts moved out of `checkout.md`; the
tinker recipe that proved there was no episodes table is gone.

## Departures

- `docs/flows/storage.md` edited (two "embedded" lines), see above.
- `docs/flows/series.md` still had `/w/` and `/c/` in its route examples, the
  URLs from before the rename. Corrected to `/g/` and `/s/` while rewriting the
  embedded-episode lines, since a flow file that names a route that does not
  exist is the same defect this task exists for.
- `docs/tinker/README.md`'s environment table said the queue was `sync` locally
  and on Cloud, and its "Mail goes to the log" trap said `MAIL_MAILER=log`
  while `.env.example` and `compose.yaml` point at Mailpit. Both corrected in
  passing, because the same table carried "Postmark (unwired)".
- `CLAUDE.md` gained the handful of rules that lived only in the Cursor copy —
  DI for console commands, typed `app/Data` shapes, money as integer cents,
  `qori:*` command names, verb-phrase trait names, the two `Concerns`
  directories, Feature versus Unit test placement, the JSON-API `Data` rules
  from `api-responses.mdc` — so reducing the copies to pointers lost nothing.
- `CLAUDE.md`'s tenancy section no longer lists the old→new noun mapping
  inline; it points at `decisions.md` for it. The mapping line was the one
  place a live document would have tripped the new claims check for a good
  reason, and the decision record is where the mapping belongs.
- `ProfileController::edit()`'s `mustVerifyEmail` prop is now the constant
  `true`. It was `$request->user() instanceof MustVerifyEmail`, meaningful
  while that could be `Staff|User|null`; narrowed through `CurrentUser` it is
  a `User`, which implements the contract, and PHPStan refused the
  always-true `instanceof`. The page reads the same value it always did.
- `StaffTwoFactorCodeRequest::code()` and `MagicLinkRequest::email()` are
  small typed accessors rather than `validated()['…']`, so the controllers do
  not re-cast.
- `ArchitectureTest` skips comment lines. Three files name a forbidden call in
  a docblock to explain why they avoid it (`PurgeSeriesCommand`,
  `SeriesAccessNotification`, `AppException`), and `ConsoleAccessTest` already
  states the principle: the call, not the word.
