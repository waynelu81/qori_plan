# T-083 — report

## Outcome

The three files every stream used to meet in are now several. The sharing
routes are declared in `routes/share/{group,setup,series,episodes,uploads,payouts}.php`
and `routes/share.php` only requires them inside the one group, so a task that
adds a payouts route and a task that adds an Episode route no longer edit the
same file; `route:list --name=share.` lists the same 37 names, verbs and paths
before and after. `Share/SeriesController` keeps the list, create, edit and
page; `Share/SeriesLifecycleController` has publish, archive, unarchive,
destroy and restore, copied action for action. `SeriesService` keeps the
Series' own lifecycle and `EpisodeService` has `add()`, `update()`, `remove()`
and `reorder()`, with §8's provider rule, the per-Series cap and the live
session guard moved with them. `Share/EpisodeController` has no inline
`validate()` left — `UpdateEpisodeRequest` and `ReorderEpisodesRequest` join
the `StoreEpisodeRequest` that already existed — and `ArchitectureTest` now
guards it instead of allow-listing it. No route name, path, Vue file or
behaviour changed; every existing test passes with a class or method name
swapped.
