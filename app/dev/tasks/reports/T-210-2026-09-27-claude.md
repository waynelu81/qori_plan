# T-210 — report

## Outcome

A Qori-hosted Episode can now only be made from an Episode upload of its own
Group that no other Episode holds, and Qori signs no Qori-hosted Episode whose
key is not one. The Episode form refuses any other key on the file field, and
`PlaybackTicketService::resolve()` — the one place such a file is signed —
answers `missing_content` instead of a link, however the row was written. One
lookup on `MediaAssetService` serves the form, the signing and `T-156`'s
deletes, so the three cannot disagree about whose file a key is.
