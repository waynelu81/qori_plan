## Current surface

Auth only so far, all Mongo-backed, no SQL:

- Fortify email/password login, registration, password reset, email verification, two-factor
- Magic link as an add-on on the same login screen (`POST /login/magic-link`, signed `GET /login/magic-link/{user}`) — not a replacement for password auth
- Passkeys (`laravel/passkeys`, swapped to a Mongo-backed `App\Models\Passkey` via `Passkeys::usePasskeyModel()`)
- `dashboard` route behind `auth` + `verified`

Product surface built so far: courses with embedded lessons, contacts,
enrolments, and the student "my learning" surface. Not built: Stripe Connect,
storage, EDM, live lessons — see docs/project-plan.md for what's specified.

### 3. ~~Migrate application data to Neon Postgres~~ — done 8 September 2026

Supersedes the previous item, "make MongoDB topology truthful everywhere". That item existed because §21.4 assumed a replica set while local dev ran a standalone `mongo:7`, so transactions would fail at runtime having passed locally. Postgres removes the problem rather than aligning it: transactions are unconditional, and there is no topology to keep truthful.

The case, from evidence in this repository rather than preference: all 15 migrations are index-only, there is not one aggregation pipeline, there are zero transaction call sites, `embedsMany` is used once, and every model has a fixed 6-15 field schema. The `'array'`-cast bug (trap 8) reached six models across two separate discoveries because nothing declares a column type. Meanwhile the adapter tax is a hand-rolled Passkey model, a swapped Sanctum model, `TruncatesMongoCollections` across 49 test files, and a standing list of unsupported Eloquent features.

- [x] Neon provisioned and migrated; local runs `postgres:18` on port 5433 to match Neon's major version; CI runs the same image.
- [x] All 17 models converted to ordinary Eloquent with ULID keys.
- [x] The 15 index-only migrations replaced by one schema migration: 19 tables, 19 primary keys, **13 unique constraints and 21 foreign keys** the database now enforces itself.
- [x] `TruncatesMongoCollections` deleted; 48 test files moved to `RefreshDatabase`; the local-database guard rewritten for Postgres.
- [x] `Lesson.content` and every other polymorphic payload moved to `jsonb`, with the `'array'` casts restored — the exact inverse of the old Mongo rule.
- [x] `mongodb/laravel-mongodb` removed from `composer.json`.
- [x] `composer ci:check` green: 375 tests, 1,115 assertions, PHPStan level 7 clean.
- [ ] Push the two in-PHP aggregations (`ProgressService::report`, `TeachDigest`/contacts counts) into the database. Deferred deliberately: they are correct and fast at current row counts, and rewriting them was not needed to complete the move.
- [ ] Keep the Atlas cluster until production has run on Neon for a while — it is the only rollback.

**Done when:** ~~green on Postgres with no Mongo dependency~~ — done, except the two deferred items above.
